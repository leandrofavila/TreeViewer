A hierarchical tree of manufacturing orders, from the parent order down to the lowest-level order within the grouping of a shipment.
Each cell contains values for the manufacturing order, item, and quantity. Cells in green indicate orders that are fully completed, while cells in red indicate orders that are either not started or partially executed. When hovering over a cell, a popup appears showing the status of each operation within the order. Clicking on a cell opens the PDF of the respective item in a new tab.
