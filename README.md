This transforms a spreadsheet containing numerical codes and technical descriptions into a hierarchical tree of manufacturing orders – from the parent order down to the lowest-level order within a shipment grouping. Each cell displays values for the manufacturing order, item, and quantity. Green cells indicate fully completed orders, while red cells denote orders not yet started or partially executed. Hovering over a cell triggers a pop-up showing the status of each operation within the order. Clicking a cell opens the corresponding item’s PDF in a new tab.
